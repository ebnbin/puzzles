第 4 章：Cube

这也是我最初作为网页游戏见到的另一个游戏。这一个是由 Paul Scott 编写的 Java 游戏 [2]。你有一个由 16 个方格组成的网格，其中六个是蓝色的；有一个立方体停在其中一个方格上。你的行动是使用方向键把立方体滚动 90 度，使它移动到相邻的方格。如果你把立方体滚到一个蓝色方格上，这个蓝色方格就会被立方体的某一面拾起；如果你把立方体的一个蓝色面滚到非蓝色的方格上，蓝色就会被重新放下。（一般来说，每当你滚动立方体时，相互接触的那两个面就会交换颜色。）你的任务是让全部六个蓝色方格同时位于立方体的六个面上。数一数你所走的步数，并尽量用最少的步数完成。

与原版的 Java 游戏不同，我的版本有一项额外的功能：一旦你掌握了立方体在方形网格上滚动的玩法，就可以换成三角形网格，滚动四面体、八面体或二十面体中的任意一种。

[2] http://www3.sympatico.ca/paulscott/cube/cube.htm

4.1 Cube 操作方式

本游戏可以使用键盘或鼠标进行游玩。

在窗口中的任意位置点击鼠标左键，都会让立方体（或其他多面体）朝鼠标指针的方向移动。

方向键同样可以用来让立方体在其方形网格上沿四个基本方向滚动。在三角形网格上，方向键与移动方向之间的对应关系则较为近似。在竖直移动没有意义的地方，该移动是不被允许的。数字小键盘上环绕着方向键的那四个键（‘7’、‘9’、‘1’、‘3’）可以用于对角线方向的移动。

（第 2.1 节中描述的所有操作同样可用。）

4.2 Cube 参数

这些参数可以通过‘类型’菜单中的‘自定义...’选项来设置。

多面体类型
选择要滚动的多面体（因而也决定了网格的形状）：四面体、立方体、八面体或二十面体。
宽度 / 顶行、高度 / 底行
在方形网格上，指水平和竖直方向的尺寸。在三角形网格上，则分别指顶行和底行上的三角形数量。
