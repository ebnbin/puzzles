第 13 章：Same Game

你有一个由彩色方格组成的网格，你必须通过高亮由不止一个同色方格构成的相邻区域来清除它们；你高亮的区域越大，得到的分数就越多（清空场地的速度也越快）。

如果你清空了网格，你就赢了。如果最后只剩下一些单个的方格（也就是说，不再有可点击的区域），你就输了。

移除一个区域会让网格的其余部分重新排列：悬空的方块会（首先）落下，然后空出来的列会由右边的列来填补。

Same Game 由 James Harvey 贡献给本合集。

13.1 Same Game 操作方式

这个游戏既可以用键盘玩，也可以用鼠标玩。

如果你左键点击一个未被选中的区域，它就会被选中（同时可能会清除当前的选择）。

如果你左键点击已被选中的区域，它就会被移除（网格的其余部分会立即重新排列）。

如果你右键点击已被选中的区域，它就会被取消选中。

方向键可以在网格中移动光标。当光标位于一个未被选中的区域中时，按空格键或回车键会选中它；再次按空格键或回车键则会像上面所说的那样把它移除。

（第 2.1 节中描述的所有操作同样可用。）

13.2 Same Game 参数

以下参数可以从‘类型’菜单上的‘自定义...’选项中获得。

宽度、高度
以方格数计的网格尺寸。
颜色数量
用来填充网格的不同颜色的数量；颜色越多，大片的同色区域就越少，因而成功清空网格的难度也就越大。
计分方式
控制用于计分的具体机制。使用默认的‘(n-2)^2’方式时，只有三个或更多方格的区域才会得到分数。使用另一种‘(n-1)^2’方式时，两个方格的区域各得一分，而更大的区域得分相对更多。
确保有解
如果勾选了这个选项（默认状态），生成的网格将保证至少有一个解。

如果你关闭它，游戏生成器就不会尝试保证网格有解；不过，它仍然会确保开局时网格上每种颜色至少有 2 个方格（因为某种颜色恰好只有一个方格的网格肯定无解）。在禁用这个选项的情况下生成的网格可能含有更多大片相连的同色区域，从而带来取得更高分数的机会；生成它们所花的时间也可能更少。
