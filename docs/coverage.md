# 四十个游戏：上游能力 → 我们的入口

上一份 `missing.md` 问的是「够不够得到」。这一份问的是另一件事：

> **每一项上游能力，我们这边有没有给它一个位置？**

区别在于：一项能力可能**够得到**（把点击原样交给引擎，它就发生了），但**没有任何按钮说它存在**
——读者只能靠试。你举的 bridges／pearl 的「这里没有桥／没有线」就是这一类：它一直做得到，
但在这一轮给它一个按钮之前，正常游玩不会发现。

## 四种标记

| 记号 | 意思 |
| --- | --- |
| ✅ | **有按钮**——键盘那一排，或方向键那一排 |
| 👆 | **只有棋盘手势**（点击 / 长按 / 长按后拖），没有任何按钮 |
| ⚙️ | **只在偏好设置里**（后端自己的对话框，我们原样显示） |
| ⬜ | **够不到** |

一条能力可以同时有 ✅ 和 👆，那是最好的情况：按钮说明它存在，手势更快。

**手势的对应关系**：点击＝左键，长按＝右键，长按后不抬手＝右键拖拽。**唯一的例外是 Net**
——它的长按发的是**中键**（锁定），因为它的右键在触摸上被上游改写过而网页版收不到那一位。
实测：点击写 `A1,1`（逆时针），长按写 `L1,1`（锁定）。

## 先看结论

### 完全够不到的（⬜）

| 游戏 | 能力 | 性质 |
| --- | --- | --- |
| **Galaxies** | 走一步「显然可推」(`h`) | **真的改棋盘**，五条里唯一一条 |
| **Pattern** | 拉矩形整片擦成「未定」（中键拖拽，上游特意不吸附） | 批量操作 |
| **Untangle** | 反向循环顶点（`Shift+Tab`） | 导航 |
| **Net** | 平移视野原点 / 移动信号源（`Shift`/`Ctrl`+方向） | 显示 |
| **Filling** | 取消整个选择（`Esc`）、切换单格的选中 | 半成品状态 |
| **Bridges** | 按桥数跳岛（数字键） | 导航快捷 |
| **Range** | 沿途标白（`Shift`+方向） | 批量快捷 |
| **Tents** | `Ctrl`+方向那一档（沿途打叉**连帐篷也覆盖**） | 批量快捷 |
| **Net** | 一次到位的顺时针 / 180°（`D` / `F`） | 快捷（左转按两三下） |
| **Twiddle** | 九宫速记键（`a`–`d`、小键盘） | 快捷（点那个块） |
| **Palisade** | Full-grid 模式下的 `Ctrl`/`Shift`+方向 | 快捷（点棋盘就够） |

### 只有手势、一个按钮都没有的（👆 且无 ✅）

**这一类才是「不对比上游就不知道它存在」的**。按游戏列：

| 游戏 | 只有手势的能力 |
| --- | --- |
| **Loopy** | **全部**——画线、打叉、擦。它是唯一一个连方向键都不给的游戏（上游不读键盘） |
| **Rect** | 切换单独一条边（点一下边）。两个键管的是拉框，零位移的键盘拖拽是「取消」不是「切边」 |
| **Netslide** | 朝**外**滑（长按外圈） |
| **Pattern** | 沿直线刷「填」/「叉」（拖 / 长按后拖） |
| **Tents** | 沿一行整排打叉（长按后拖） |
| **Tracks** | 沿路铺轨 / 打叉的**整条路径**（拖 / 长按后拖） |
| **Mosaic** | 沿直线刷整段（拖 / 长按后拖） |
| **Signpost** | 断开连接（拖出棋盘外；左拖断后、右拖断前） |
| **Filling** | 拖拽累加多选 |
| **Magnets** | 划掉棋盘外沿的线索 |
| **Towers · Undead** | 划掉外沿线索 |
| **Unequal** | 划掉格子之间的大小关系 |
| **Singles** | 开关「显示黑格上的数字」（**点棋盘外面**） |
| **Undead** | 循环计数显示样式（**长按棋盘上方那排计数**） |
| **Cube · Fifteen · Inertia** | 点棋盘按方位角走（三个都有方向键，所以能力不丢，只是这条路没有按钮） |

### 只在偏好设置里的（⚙️）

- **Bridges** 显示可能的桥位（`G`）
- **Guess** 颜色上的字母标签（`L`）
- **Map** 区域编号（`L`）
- **Fifteen** 方向键语义、**Slant / Range** 左右键对调、**Palisade** 光标模式、
  **Loopy** 自动顺延、**Solo 一族** 铅笔高亮保留

## 这份表能读出来的

- **「只有手势」的那一类几乎全是同一种东西：批量／连续操作。** 拖出来的路径、刷出来的一行、
  拖出棋盘的断开——十五个游戏里有九个是这个形状。它们共同的问题是**没有任何东西宣告它存在**：
  一个只点不拖的读者，会以为 tracks 只能一格一格铺。
- **划掉线索**（towers、unequal、magnets、undead 四个）是第二种：它在棋盘**外沿**，
  而读者不会想到棋盘外面能点。
- **两处「点了才知道」的显示开关**（singles 点棋盘外、undead 长按计数区）是最隐蔽的，
  连上游手册都不提。
- **真正一项能力都不少、而且每项都有按钮的**：Sixteen、Blackbox、Guess、Mines、Samegame、
  Dominosa、Light Up、Flood。
- **Loopy 是唯一一个一个按钮都没有的**，而且不是我们的选择——上游不读键盘。
