第 20 章：Slant

你面前有一个由方格组成的网格。你的目标是在每个方格中画一条对角线，并选择每条线的倾斜方向，使得下列条件得到满足：

  • 这些对角线绝不构成环路。
  • 任何带圈数字所在的点，恰好有与该数字相同数量的线在此交汇。（因此，4 是一个十字形的中心，而 0 是一个菱形的中心 – 或者更确切地说，是部分菱形的中心，因为 0 绝不可能出现在网格中间，那样会立刻造成环路。）

这个谜题的创意归功于 Nikoli [8]。

[8] https://www.nikoli.co.jp/ja/puzzles/gokigen_naname/（日文）

20.1 Slant 操作方式

在空白方格中左键单击，会在其中放置一个 \（一条向左倾斜的线，即从方格的左上角延伸到右下角）。在空白方格中右键单击，会在其中放置一个 /（向右倾斜，从右上角延伸到左下角）。

继续单击任一按键，会在方格的三种可能内容之间循环。因此，如果你在空白方格中反复左键单击，它会从空白变成 \，再变成 /，然后回到空白；如果你反复右键单击，该方格会从空白变成 /，再变成 \，然后回到空白。（因此，如果需要，你完全可以只用一个按键来玩这个游戏。）

你也可以用方向键在网格中移动。按回车键或空格键会分别放置 \ 或 /，随后按上述方式循环。你还可以按 / 或 \ 来分别放置 / 或 \，而与光标所在方格中已有的内容无关。退格键会移除光标所在方格中的任何线条。

（第 2.1 节中描述的所有操作同样可用。）

20.2 Slant 参数

这些参数可通过‘类型’菜单上的‘自定义...’选项进行设置。

宽度、高度
网格的大小，以方格数计。
难度
控制所生成谜题的难度。在困难级别下，你需要根据方格之间关系的知识来进行推理，而不是总能一次推出某一个方格的确切内容。（例如，你可能知道两个方格的倾斜方向相同，即使你还不知道那是哪个方向，而这可能让你推出关于另外一些方格的结论。）即使在困难级别下，也绝不需要猜测和回溯。

20.3 Slant 用户偏好设置

在支持用户偏好设置的平台上，‘游戏’菜单上的‘偏好设置’选项可以让你配置两个鼠标按键的作用方向。
